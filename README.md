# attendance

고등학교 학급의 출석, 지각, 조퇴, 결석을 기록하고 누적 현황을 확인하는 반응형 웹 앱입니다.

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열거나, 저장소 루트에서 로컬 웹 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 주요 기능

- 날짜별 출결 기록과 전체 출석 처리
- 1~7교시별 출석 `/` 표시와 날짜별 출결 사유 입력
- 학생별 월간 출석·지각·조퇴·결석 누적 통계
- 이름·번호 검색과 출결 상태 필터
- 학생 추가 및 CSV 내보내기
- 브라우저 로컬 저장소 자동 저장

출결 정보는 현재 브라우저에 저장되므로, 다른 기기와 자동으로 동기화되지 않습니다. 정기적으로 CSV 파일을 내려받아 보관하세요.
